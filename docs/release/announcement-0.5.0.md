# OpenCohost 0.5.0 announcement (draft)

Short versions for Discord and GitHub. Replace `<release link>` before posting.

## Español

**OpenCohost 0.5.0**

- Novedades: nuevo asistente de primer uso con puntos de control (si lo interrumpes, continúas donde quedaste), proveedores en la nube con prueba de clave de Gemini que funciona, diagnóstico de cada turno y streaming más estable.
- Importante: al actualizar desde 0.3.0 y 0.5.0-alpha se conservan tus perfiles, ajustes, voz/idioma, recursos y claves de API; únicamente las memorias empiezan desde cero debido al cambio en su formato de almacenamiento.
- Cómo actualizar: ejecuta el instalador nuevo; intentará quitar la versión anterior por sí mismo. Si avisa que no puede, desinstala la anterior desde Configuración de Windows -> Aplicaciones y vuelve a ejecutarlo. La versión anterior puede dejar una carpeta `resources\runtime` en su carpeta de instalación; puedes borrarla a mano para recuperar espacio.
- El instalador no está firmado, así que Windows SmartScreen puede mostrar una advertencia. Antes de ejecutarlo, verifica el SHA256 del archivo con `SHA256SUMS`.
- Descarga: <release link>

## English

**OpenCohost 0.5.0**

- What's new: a new first-run wizard with checkpoints (if you stop, you resume where you left off), cloud providers with a Gemini key test that works, per-turn diagnostics, and more stable streaming.
- Important: when upgrading from 0.3.0 and 0.5.0-alpha, your profiles, settings, voice/locale preferences, assets, and API keys are preserved; only memories start fresh because the memory storage format changed.
- How to upgrade: run the new installer; it tries to remove the previous version itself. If it says it cannot, uninstall the previous version from Windows Settings -> Apps and run it again. The previous version may leave a `resources\runtime` folder in its old install folder; you can delete it manually to reclaim space.
- The installer is unsigned, so Windows SmartScreen may show a warning. Before running it, verify the file's SHA256 against `SHA256SUMS`.
- Download: <release link>
